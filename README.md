# Tom Thomas Client Portal

Client portal for Tom Thomas Web & Media. Built with Next.js, Supabase, and deployed on Vercel.

## Setup

1. Create a Supabase project and run the schema SQL
2. Upload this code to a GitHub repository
3. Connect the repo to Vercel
4. Add environment variables in Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
5. Deploy
